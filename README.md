# Sistema de Gerenciamento e Entrega de Pedidos (Grupo 1)

Projeto de Estrutura de Dados focado na gestão de pedidos e fila de entregas utilizando estrutura de dados linear, com operações de busca, seleção e ordenação.

## Resumo do Projeto
- **Estrutura de dados:** Lista / fila linear para controle de pedidos e entregas.
- **Algoritmos aplicados:** Busca (por código, cliente ou endereço), seleção e ordenação (por prioridade).
- **Organização do código:** Modularizado em `pedidos.h`, `pedidos.cpp` e `main.cpp`.

## Como Compilar e Executar
Abra o projeto em C++ (como o Dev-C++) ou compile no terminal com:
`g++ main.cpp pedidos.cpp -o SistemaPedidos`
